# FactPeek Prototype

An English-only, responsive media-literacy learning prototype based on the FactPeek website project brief.

## Included

- Welcome splash plus a complete front-end registration → sign-in → Home flow
- Home, the daily challenge, and three distinct micro-lessons
- 38 research-based cases with photographic cards, source links, and 10–15 minute practice estimates
- Balanced truth types: verified real news, AI-generated fake content, and other false or misleading claims
- Topic and truth-type filters across nine color-coded library categories
- Library search and category filters
- Case reading, clue marking, hints with score deductions, and mixed quiz formats
- Per-question answer reviews showing the learner's answer, best answer, why it is correct, and why alternatives do not fit
- An interactive four-step beginner guide with a guided starter case
- Site-wide user feedback plus case-specific issue reporting, stored in the prototype browser
- Animated right/wrong feedback, game sounds, progress, rewards, and completion summaries
- Stamina with a required learning recharge after repeated mistakes
- Favorites, sharing, helpful votes, source following, and local community comments
- Learning streaks, XP levels, weekly rank, a wrong-answer book, completion tracking, and 12 unlockable badges
- Fixed prototype flow for Analyze My Story
- Profile learning data, saved cases, badges, rank, and skill profile, persisted in the browser
- Mobile layout, keyboard support, dark mode, and reduced-motion support

## Local preview

Run a static server in this directory, for example:

```bash
python3 -m http.server 4173
```

Then open `http://localhost:4173`.

## Notes

This is a front-end prototype. It does not include real accounts, a database, or an online fact-checking service. The analysis screen is clearly labeled as a fixed educational demo.
