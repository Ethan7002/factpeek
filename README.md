# FactPeek Prototype

A responsive, clickable prototype based on the FactPeek website project brief.

## Included

- English sign-in welcome screen and prototype access flow
- Home and the daily challenge
- Library search, category filters, and case cards
- Case reading, clue marking, quiz, and feedback
- Fixed prototype flow for Analyze My Story
- Profile learning data, badges, and skill profile
- Mobile layout, keyboard support, dark mode, and reduced-motion support

## Local preview

Run a static server in this directory, for example:

```bash
python3 -m http.server 4173
```

Then open `http://localhost:4173`.

## Notes

This is a front-end prototype. It does not include real accounts, a database, or an online fact-checking service. The analysis screen is clearly labeled as a fixed educational demo.
